# Phoenix Labels, Stickers & Printing

Official static website for **Phoenix Labels, Stickers & Printing**, specializing in garment accessories, printing, silicone, heat transfers, woven labels, tags, and digital printing.

## Live Website
Hosted on GitHub Pages:
[https://arivomtechnologies.github.io/Phoenix/](https://arivomtechnologies.github.io/Phoenix/)

## Features
- **Pure Static HTML5/CSS3/JavaScript:** Fast, lightweight, and serverless.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop viewing.
- **Product Gallery:** High-resolution product showcase and image carousel.
- **Contact Info & Inquiries:** Direct phone, email, and Google Maps location.

## Local Development
To preview the website locally, run:
```bash
python3 -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your web browser.
